# WEB422 Lab 06 – User Profiles with Jotai

A simple Next.js app for managing users with Jotai global state.

## What it does
- Home page lists all users with their name and email
- Clicking a user opens an edit form at `/users/[id]`
- `/users/add` adds a new user
- Forms check that name and email aren't empty

## Concepts practiced
- Global state with Jotai atoms
- Forms and validation with React Hook Form
- Dynamic routing in the Pages Router
- Styling with React Bootstrap

## Run it
npm install
npm run dev

Then open http://localhost:3000
